# DrishthiNet (Apex Operational Console)
### A Hybrid AI-Driven Unified Video Surveillance, Intelligence & Forensic Platform for State-Wide Law Enforcement in Gujarat

> [!WARNING]
> **PROTOTYPE • SIMULATED DATA • NOT CONNECTED TO LIVE SYSTEMS**
>
> **NO LIVE CCTV • NO REAL BIOMETRICS • NO GOVERNMENT API CONNECTIONS**
>
> This application is an **interactive presentation prototype** created to accompany a project proposal for Gujarat Police.
>
> - **100% Synthetic Data:** All camera nodes (405 representative edge markers representing Gujarat's 80,000+ fleet), license plates (`GJ-01-XX-4821`), facial watchlist identifiers (`WL-0027`), and telemetry metrics are generated locally client-side.
> - **Zero Live Government Database Connections:** No real connections exist to VAHAN, SARTHI, eGujCop, NAFIS, CCTNS, ICJS, or MeghRaj cloud servers.
> - **Simulated AI Inference:** ANPR, facial watchlist matches, and crowd surge alerts are generated by an in-memory event ticker every 6 seconds (with a live presenter pause/play toggle).
> - **Illustrative Architecture:** Demonstrates how 26 fragmented state departments can federate into a common intelligence bus without replacing existing cameras.

---

## 1. Core Architectural Principle

> **"PRESERVE EXISTING INFRASTRUCTURE. ADD A UNIFIED INTELLIGENCE LAYER."**

The DrishthiNet platform bridges Gujarat's fragmented surveillance landscape across three architectural tiers:
1. **Layer 1 (Registry & GIS Foundation):** Camera Registry, GIS Geolocation, Health Diagnostics, and Network Topology.
2. **Layer 2 (VMS Federation Middleware):** ONVIF, RTSP/WebRTC proxies, metadata normalizers, and vendor hardware adapters (CP Plus, Hikvision, Dahua, Bosch, Axis).
3. **Layer 3 (Central Intelligence Engine):** ANPR, AI analytics, real-time alert engine, investigation desk, SHA-256 forensic audit ledger, and cross-district tracking.

## 2. Platform Navigation (12 Comprehensive Modules)

### OVERVIEW
- **Command & Control:** Single pane of glass featuring 4 core KPIs (80,000+ Total Cameras, 96%+ Online, 45 Active Alerts, < 30 sec Alert Response), statewide Gujarat Leaflet map with 405 representative locations, and live incident queue with presenter controls.

### OPERATIONS
- **Live Incident Center (Investigation):** Incident summary, simulated surveillance frame, 5-stage timeline (`Detected` ➔ `AI Analysis` ➔ `Acknowledged` ➔ `Dispatched` ➔ `Resolved`), related correlations, and watermarked evidence package exporter.
- **Cross-District Tracking:** Smooth animated trajectory reconstruction of target vehicle `SIM-VH-0238` across Ahmedabad, Vadodara, Bharuch, and Surat with Play/Pause/Reset/Speed controls and summary strip (`4 observations • 4 locations • 3 districts • 32 min journey`).
- **Camera Registry:** Searchable, multi-filterable asset inventory with slide-over telemetry drawer and simulated CCTV monitor.

### INTELLIGENCE
- **AI Analytics:** Dedicated hub demonstrating 7 vision pipelines (ANPR, Face/Watchlist Matching with synthetic vector scores, Multi-Class Object Detection, Crowd Analysis, Perimeter Detection, Abandoned Objects, Vehicle Analytics).
- **GIS & Network Topology:** Spatial backbone analysis with district breakdown and an interactive 5 km spatial radius query.

### SYSTEM
- **Health & O&M:** District availability bar charts, 30-day MTTR reduction trends, predictive maintenance queue with at-risk cameras (`CAM-AHM-0182` etc.), and simulated work-order ticketing.
- **Forensic Audit Trail:** Browser-native SHA-256 blockchain ledger with one-click chain integrity verification and tamper simulation.
- **Integration Board:** Visual topology showing the Central Intelligence Layer connecting 26 state departments and proposed national databases (VAHAN, SARTHI, eGujCop, NAFIS, CCTNS, ICJS).
- **Security & Privacy:** Proposed Zero Trust architecture, RBAC, MFA, AES-256 encryption, network segmentation, and DPDP Act 2023 compliance principles.

### PROJECT
- **Architecture View:** Visual 3-tier diagram illustrating the middleware federation concept over 80,000+ cameras.
- **Proposal & Roadmap:** 36-month phased rollout plan (Months 0–36) and institutional deployment pre-requisites.
- **Demo Role Hub:** Operational personas for *Control Room Operator*, *District SP*, and *State Admin* that tailor console focus.

## 3. Local Setup & Execution

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Launch
```bash
# 1. Navigate to the prototype directory
cd drishthinet-prototype

# 2. Install dependencies (if not already installed)
npm install

# 3. Start local development server
npm run dev
```

Open your browser at `http://localhost:5173/`.

## 4. Mandatory Institutional Pre-requisites Before Real Deployment

This prototype is a conceptual proposal demonstration. Before real-world deployment, the following milestones are mandated:
- **DPDP Act 2023 Compliance:** Data Protection Impact Assessment (DPIA) and automated non-biometric redaction.
- **Human-in-the-Loop Protocol:** Mandatory human officer confirmation prior to law-enforcement dispatches.
- **Inter-Agency MoUs:** Data-custody agreements preserving raw video within local departmental silos.
- **Evidentiary HSM Seals:** Hardware Security Module timestamping under Indian Evidence Act Section 65B.
- **Cert-In Security Audit:** Independent security and penetration audit of all software components.
